# 串口调试助手 · 多窗口（Qt / PyQt5）

一个基于 **PyQt5 + pyserial** 的多窗口串口调试工具，支持同时打开 **1~4 个串口**，
每个串口独立配置连接参数、独立收发，窗口固定水平等分布局。

## 环境要求

- Python 3.8+
- PyQt5 >= 5.15
- pyserial >= 3.5

```bash
pip install -r requirements.txt
```

## 运行

**最简单：双击 `run.bat`**（使用本机安装的 Python312，自带 PyQt5 + pyserial）。

也可以命令行运行（在项目根目录 `串口工具/` 下）：

```powershell
# PowerShell（注意带引号路径前要加 & 调用运算符）
& "C:\Users\35370\AppData\Local\Programs\Python\Python312\python.exe" -X utf8 -u main.py

# 或使用 PATH 中的 python（需已安装 PyQt5、pyserial）
python main.py
```

## 功能一览

### 多窗口布局

| 串口数量 | 布局 |
| --- | --- |
| 1 | 整窗 |
| 2 | 左右平分 1×2 |
| 3 | 横向三等分 1×3 |
| 4 | 固定 2×2 |

- 工具栏「串口数量」下拉框选择 1~4，布局实时刷新；
- **4 个串口时工具栏自动移到左侧竖排**，给 2×2 网格腾出更多空间；
- 每个面板由 `QGridLayout` 等分拉伸，窗口缩放时始终均分。

### 每个面板（独立配置）

- **连接参数**：串口、波特率（下拉选择，300~2M，含常用非标速率）、**格式**（数据位/校验位/停止位合并下拉，如 `8N1`、`7E1`）、流控；
- **批量开关**：工具栏单个切换按钮「打开 / 关闭」同时开启/关闭所有串口（有串口已打开时按钮变红色「关闭」，否则绿色「打开」；面板无单独开关按钮）；
- **打开状态**：面板标题处绿色圆点指示串口已打开；
- **接收区**：
  - 自动滚屏（默认开启）；**关闭自动滚屏后，日志视图停留在关闭那一刻**，接收不中断，可用鼠标自由滑动日志；
  - **右键菜单**：复制（无选区时复制最后一行）/ 复制所选内容 / 全选 / 清空 / 保存日志；
  - **关键词高亮**：工具栏「设置」→「日志关键词高亮」可添加关键词与颜色（不区分大小写），在接收区以字体颜色自动着色，设置会记住；
  - **行过滤**：设置页「日志行过滤」有**独立的关键词列表**，勾选启用后接收区**只显示包含过滤关键词的行**（时间戳随行保留）；**完整日志始终保留**，关闭过滤即可找回之前被隐藏的行；
  - HEX 显示 / 时间戳 / 显示发送回显；
  - 清空、保存日志到文件、接收/发送字节统计；
  - 接收数据分批刷新（60ms 合并），高速数据不卡界面；
- **发送区**：
  - 多行输入，**回车即发送，Shift+回车换行**；
  - HEX 发送、**转义解析**（`\r` `\n` `\t` `\xHH` `\uHHHH` 等自动解析为实际字节，未知转义原样保留）；
  - **换行选项**（无 / CR / LF / CRLF，发送时自动追加）、定时发送（10ms~600s）；
  - 单独发送按钮，各面板独立发送。

### 窗口行为

- **自定义标题栏**：无边框窗口（QWidget + FramelessWindowHint），标题栏独占整行、按钮可靠最右，右上角依次为 **📍图钉(置顶) → ☀主题切换 → ─最小化 → □最大化 → ✕关闭**；标题栏可拖动、边缘可缩放、最大化不遮挡任务栏；
- **窗口置顶**：标题栏图钉按钮，不固定时图钉横着、固定（置顶）时图钉斜向；
- **检查更新**：工具栏「检查更新」按钮，从更新清单（version.json，GitHub/Gitee Releases 或任意静态托管）拉取最新版本，发现新版可下载新版安装程序并安装；更新地址在 `serial_tool/updater.py` 的 `UPDATE_MANIFEST_URL` 配置；
- **白天/夜间主题切换**：点击标题栏太阳/月亮图标，以图标为中心**圆形扩散过渡**切换主题，选择会记住，下次启动保持；
- **配置记忆**：退出时自动保存串口数量、主题、每个串口的连接参数（端口/波特率/格式/流控）与收发显示选项，下次启动自动恢复；
- **窗口居中**：默认开启「窗口居中」，窗口始终保持在屏幕中央（缩放时自动回中），可取消勾选自由拖动；
- **自适应窗口**：切换串口数量时，自动按面板数量调整窗口大小；若所需尺寸接近或超过屏幕则自动最大化；
- **最大化/还原**：标题栏按钮或工具栏「最大化」均可。

## 构建安装包

- 需先安装 **Inno Setup 6**（免费，winget：`winget install JRSoftware.InnoSetup`）
- 运行 `scripts/build_installer.ps1`（自动打包 exe → 编译安装程序），产物：`installer\SerialTool-Setup-<版本>.exe`
- 安装程序支持**用户自选安装位置**、开始菜单/桌面快捷方式、卸载入口，默认按用户目录安装（无需管理员）

## 备注

- 串口打开失败时（如端口被占用）会给出错误提示；「全部打开」会汇总所有失败原因。
- 接收日志上限为 20 万行，超出自动丢弃最旧内容，防止内存无限增长。
